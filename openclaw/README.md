# Rizamo for OpenClaw

Publish and schedule posts on Instagram, Facebook, TikTok, YouTube and Threads, see how they did, and answer comments and messages, from OpenClaw.

This plugin adds Rizamo's remote MCP server (`https://mcp.rizamo.com/mcp`) and the Rizamo skill. Rizamo hosts the server: the plugin holds no code and no keys.

## Install

```sh
openclaw plugins install clawhub:rizamo-mcp
```

Start a new session, then open Settings, then MCP, and choose Sign in for Rizamo. Sign in to Rizamo in the browser and choose the profiles OpenClaw can use.

You need a Rizamo account, free for two social accounts, with at least one account connected in Rizamo's web app.

## Ideas

- "Schedule this photo to Instagram and Facebook for Friday at 9."
- "Every Monday at 9, send me last week's results here."
- "Every morning, tell me which comments and messages need a reply."

OpenClaw shows you what it will publish, reply or delete and waits for your yes, as the skill tells it to. You can remove its access at any time in Rizamo.
