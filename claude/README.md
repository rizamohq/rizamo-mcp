# Rizamo for Claude

This folder is the Rizamo plugin for Claude Code, Cowork and the Claude apps, as the Claude plugin directory reads it. It adds Rizamo's remote MCP server, `https://mcp.rizamo.com/mcp`. You sign in with OAuth and choose the profiles Claude can reach. Nothing is installed or run on your machine.

Setup for every other client is in the [repository's README](../README.md).
